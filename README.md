# JARVIS AI — Mobile PWA

A mobile-first futuristic personal assistant prototype.

## Included
- Futuristic JARVIS interface
- Animated AI core states
- Chat UI
- Local memory
- Local history
- Hindi/Hinglish voice input using browser SpeechRecognition when supported
- Text-to-speech
- Optional Gemini API integration (API key stored locally)
- PWA manifest

## Run
Open `index.html` in a browser. For microphone access, use HTTPS hosting or localhost.

## Gemini
Open Settings and paste your Gemini API key. For a production app, move API calls behind a server-side proxy; do not ship a secret key in a public client.
